# What am I Building?

### Rendering part of the [VPipeline](/vpipeline/)  
    
Currently working on the rending part of the vpipeline.  
In my view this is the hardest part of VPipeline because it has to be deterministic while being dynamic, using both in same sentence is kind of contradictory.  
  
I mean that the engine has to follow the rendering rules but with creativity.  
There are two ways:  
- Letting agent decide 100% or
- Letting pipeline decide
  
I chose both, means, pipeline decides the flow and agent creates the data.
